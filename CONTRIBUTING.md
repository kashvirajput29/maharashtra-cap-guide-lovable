# Contributing to Maharashtra CAP Guide

Thank you for helping make engineering admissions in Maharashtra easier to navigate! Whether you are fixing a UI bug, improving AI prompt logic, or updating CAP round cutoff data, contributions are welcome.

## Ways to Contribute
1. **Report Outdated Cutoff Data:** Flag discrepancies in DTE college codes, branch names, or category percentiles (OPEN, OBC, SC, ST, EWS, TFWS, SEBC).
2. **Enhance Filters & UI:** Improve search speed, mobile responsiveness, or comparison tables.
3. **Documentation:** Clarify setup instructions or add guides for future admission cycles.

## Branch Naming Convention
Please create a dedicated branch from `main` using one of the following prefixes:
- `feat/<short-description>` — New UI components, filters, or AI features
- `data/<college-or-round>` — Updates to CAP cutoff percentiles or institute lists
- `fix/<issue-description>` — Bug fixes or broken link repairs
- `docs/<topic>` — Updates to `README.md` or documentation files
